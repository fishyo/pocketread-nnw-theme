TYPOGRAPHY & DETAILS

What changed

Six small adjustments aimed at common friction in daily bilingual RSS reading.

01 / PARAGRAPH RHYTHM

Flush-left, tighter paragraphs

No first-line CJK indentation. Short news briefs often run 2–3 lines per paragraph, where repeated indents feel choppy. Flush-left alignment with 0.35em CJK spacing keeps scanning steady.

02 / FONT SCALE

1.07x dynamic type scale

Scales NetNewsWire's [[font-size]] by 1.07x (~18.2px at default) with 22px horizontal padding, while still honoring system Dynamic Type.

03 / FONT WEIGHT

Semibold 600 for bold text

Default 700 bold can look heavy in PingFang SC body copy. Setting <b> and <strong> to 600 with slightly darker ink keeps emphasis readable without visual weight.

04 / COLOR & DARK MODE

Warm paper & dark mode cleanup

Light mode pairs warm paper #FAF8F4 with charcoal text #5A5957; dark mode uses #0B0B0D with soft white #DFDDD7, overriding hardcoded dark inline colors (such as #333) from feeds.

05 / HTML CLEANUP

Empty-line cleanup for CJK feeds

Collapses empty paragraphs, repeated <br> spacers, and empty wrapper nodes common in Chinese RSS feeds, and normalizes .article-paragraph blocks.

06 / ENGLISH

English spacing & heading wrap

English body copy uses 0.48em paragraph spacing. Headings stay left-aligned with text-wrap: pretty to reduce orphan words on the final line.

Manual install

  1. Download PocketRead.nnwtheme.zip to Files or Downloads.
  2. Unzip to get the PocketRead.nnwtheme folder.
  3. On iOS/iPadOS, share it to NetNewsWire; on macOS, double-click to install.
  4. Select PocketRead under NetNewsWire Settings ➔ Article Theme.

* If upgrading from an older copy, choose Overwrite when prompted.
